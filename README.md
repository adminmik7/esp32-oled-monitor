# 📊 esp32-oled-monitor — ESP32 + OLED PC Monitor

**Windows Edition.** Отображение GPU и RAM на OLED экране 0.96" (128x64).

## 🔌 Подключение

| ESP32 | OLED 0.96" (I2C) |
|---|---|
| 3V3 | VCC |
| GND | GND |
| GPIO 21 (SDA) | SDA |
| GPIO 22 (SCL) | SCL |

## 🚀 Запуск в Windows

1.  Установи **Python** (не забудь галочку "Add to PATH").
2.  Скачай этот репозиторий.
3.  Дважды кликни по **`start.bat`**.

Скрипт сам найдет ESP32, установит библиотеки и начнет отправку данных.

## 📦 Зависимости для Arduino IDE
- `Adafruit SSD1306`
- `Adafruit GFX Library`

## 📝 Последние изменения

- **GPU вместо CPU** — `sender.py` теперь считывает нагрузку GPU через `nvidia-smi` вместо `psutil.cpu_percent()`. Данные отправляются в формате `GPU:X|RAM:Y`.
- **Индикатор отсутствия данных** — если данные не поступают 3 секунды, в правом верхнем углу экрана мигает квадрат 5x5 пикселей.
- **Прогрессбары увеличены** — толщина прогрессбаров CPU и RAM увеличена до 10px.
- **Таймаут уменьшен** — порог определения отсутствия данных сокращён с 5 до 3 секунд.
- **`showWait()`** — при отсутствии данных всегда показывается мигающий индикатор (старый пустой экран убран).
