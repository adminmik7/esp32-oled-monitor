# ESP32 OLED Monitor v1.0.1

Мониторинг загрузки процессора (CPU) и оперативной памяти (RAM) вашего компьютера с выводом данных на OLED-дисплей 0.96" через ESP32.

## 🚀 Особенности
*   **USB-подключение:** Надежная передача данных без задержек Wi-Fi.
*   **Авто-детект:** Скрипт автоматически находит COM-порт вашей платы ESP32.
*   **Plug & Play:** Зависимости (`psutil`, `pyserial`) устанавливаются сами при первом запуске.
*   **Компактный дизайн:** Удобное двухколоночное отображение на экране 128x64.

## 📦 Комплектующие
1.  Плата ESP32 (любая модель с USB, например, DevKit V1).
2.  OLED-дисплей 0.96" I2C (на контроллере SSD1306).
3.  Компьютер с установленным Python 3.

## 🔌 Схема подключения (I2C)
| OLED Pin | ESP32 Pin |
| :--- | :--- |
| VCC | 3.3V |
| GND | GND |
| SCL | GPIO 22 |
| SDA | GPIO 21 |

## 🛠️ Установка и запуск

### 1. Прошивка ESP32
1.  Откройте файл `esp32_oled.ino` в Arduino IDE.
2.  Убедитесь, что установлены библиотеки `Adafruit SSD1306` и `Adafruit GFX`.
3.  Выберите свою плату и порт, затем нажмите **Upload**.

### 2. Запуск на ПК
1.  Откройте терминал в папке проекта.
2.  Запустите скрипт:
    ```bash
    python sender.py
    ```
3.  Скрипт сам найдет порт и начнет отправку данных.
