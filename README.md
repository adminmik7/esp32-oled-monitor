# ESP32 OLED Monitor v0.2

Мониторинг загрузки CPU и RAM с выводом на OLED-экран через **USB-кабель**.

## 🚀 Особенности v0.2
*   **USB Connection:** Надежное подключение без Wi-Fi.
*   **Auto-Detect:** Скрипт сам находит COM-порт с ESP32.
*   **Auto-Install:** Автоматическая установка зависимостей (`psutil`, `pyserial`).

## 🛠️ Установка
1.  Подключи ESP32 к ПК.
2.  Запусти `sender.py`.
3.  Скрипт сам всё настроит и начнет передачу данных.

## 📦 Зависимости
*   Python 3.x
*   Библиотеки: `psutil`, `pyserial` (устанавливаются автоматически).
