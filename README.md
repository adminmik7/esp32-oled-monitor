# 📊 esp32-oled-monitor — ESP32 + OLED PC Monitor

**Windows Edition.** Отображение GPU и RAM на OLED экране 0.96" (128x64).

## 🔌 Подключение

| ESP32 | OLED 0.96" (I2C) |
|---|---|
| 3V3 | VCC |
| GND | GND |
| GPIO 21 (SDA) | SDA |
| GPIO 22 (SCL) | SCL |

## 🚀 Запуск

1.  Установи **Python** (не забудь галочку "Add to PATH").
2.  Скачай этот репозиторий.
3.  Запусти `sender.py`:

```
python sender.py
```

Скрипт сам найдет ESP32, установит библиотеки и начнет отправку данных.

## 📦 Зависимости

### Arduino IDE
- `Adafruit SSD1306`
- `Adafruit GFX Library`

### Python (автоматически)
- `psutil`
- `pyserial`

## 🌐 Веб-интерфейс

ESP32 запускает веб-сервер с двумя страницами:

- **`/`** — мониторинг GPU и RAM в реальном времени (графики, статус подключения).
- **`/settings`** — настройки WiFi (SSID и пароль).

IP адрес ESP32 выводится в Serial Monitor при подключении.

## 📝 Последние изменения

- **GPU вместо CPU** — `sender.py` считывает нагрузку GPU через `nvidia-smi`. Данные отправляются в формате `GPU:X|RAM:Y|TS:Z`.
- **Индикатор отсутствия данных** — если данные не поступают 3 секунды, на OLED мигает квадрат 5x5 пикселей.
- **Прогрессбары** — толщина прогрессбаров GPU и RAM — 12px.
- **`showNoDataBlink()`** — при отсутствии данных показывается мигающий индикатор.
- **Веб-интерфейс** — графики с горизонтальной и вертикальной сеткой, фиксированный диапазон 0-100%.
- **Статус онлайн/оффлайн** — индикатор окрашен в зелёный/жёлтый цвет.
- **Настройки WiFi** — страница `/settings` для смены SSID и пароля через браузер.
